# PETATOE — AUDIT-BACKEND-01

مراجعة حمل Backend من مصدر **18.56.141 / P3** — 8 نوفمبر 2026.

هذه حزمة فحص فقط. لا ترفعها إلى GitHub كتحديث، ولا تشغّل migrations قديمة. لا ملفات تشغيل أو SQL أو صلاحيات أو حسابات مالية عُدّلت.

النتائج المهمة:

- quotations هو المفتاح الداخلي لشاشة **عقود العملاء**، وله روابط بالفواتير والمواعيد والتقارير؛ ليس مهجورًا لمجرد غياب اسم «عروض الأسعار».
- اشتراك تنفيذ المواعيد يبدأ قبل فتح الشاشة، ويستطيع حدث أن يطلب بياناتها بالخلفية.
- render المهام يطلب اقتراحات، والكاش المشترك يبدأ refresh حتى عند وجود نسخة حديثة ولا يدمج كل طلب متزامن.
- count دقيق على customers يسبق مزامنة كاشه؛ يطابق طلب timeout المرسل. حذف الفحص عشوائيًا قد يكسر إصلاح اختلاف الكاش.
- توجد تحميلات lifecycle لوحدات غير مفتوحة، وتحميل مصادر تقارير أكثر من مرة.
- سبع Views بلا مرجع مباشر ظاهر في العميل ليست دليلًا على حمل دوري أو عدم وجود مستخدم خارجي. لا حذف لأي View.

راجع التقرير الكامل في `docs/backend-audit/AUDIT-BACKEND-01_AR.md`؛ فيه الأسباب والأثر والنطاق وأول إصلاح مرشح وخطة التراجع واختبارات القبول وحدود الأدلة.

## الخطوة الحالية: قراءة مقاييس موجودة فقط

1. افتح التطبيق بحسابك المعتاد وعلى dashboard. لا تنشئ أو تعدّل أي معاملة لأجل الفحص.
2. افتح Console والصق محتوى `scripts/audit/backend-load-passive-capture.js` مرة واحدة.
3. بعد ظهور نص JSON، اكتب `copy($_)` مباشرة لنسخه، وأرسل النص الناتج.

السكربت لا يبدأ fetch أو RPC، ولا يفتح/يغلق قناة، ولا يغير الكاش أو المصادقة، ولا يعيد المحاولة. يقرأ مقاييس في الذاكرة ويزيل تفاصيل URLs وأسماء القنوات والهوية من النتيجة. لا ترسل Headers أو Tokens أو HAR.

الناتج عينة من التبويب الحالي فقط؛ لا يثبت أن ميزة غير مستخدمة، ولا يساوي CPU أو حجم Logs. لا حاجة إلى مواصلة البحث في Logs الآن للحصول على هذه اللقطة.

## إعادة المحاكاة اختياريًا على الجهاز المحلي

الأداة `scripts/audit/backend-load-offline-replay.mjs` تُشغّل المصدر في Node مع mocks دون شبكة أو قاعدة بيانات. تحتاج نسخة المصدر المطابقة لـ18.56.141:

```bash
node scripts/audit/backend-load-offline-replay.mjs /absolute/path/to/matching-source
```

نتائج المحاكاة التي نفذها المساعد موجودة بالفعل في LOCAL_TRACE_RESULTS.json. ليست اختبارات Production ولا تتطلب تشغيلًا من المستخدم.

أول تغيير مرشح لاحقًا: ضبط دورة حياة اشتراك تنفيذ المواعيد فقط، مع انتظار cleanup غير المتزامن وحماية التنقل السريع. إعداد ونشر هذه الخطوة لهما حزمة مستقلة؛ الحزمة الحالية لا تنفذها.
